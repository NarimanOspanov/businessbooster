# «Как в жизни» — 3D-сцены для опытов (бриф)

Open Edu AI (saudager.ai) — бесплатные интерактивные уроки. В опыте (страница `labs/<тема>/index.html`)
слева площадка со схемой (SVG). Переключатель «Схема | Как в жизни» показывает ту же установку
объёмно, на Three.js, как настоящие приборы на деревянном столе. Сцена строится из **живого состояния
опыта**: двигаете ползунок на схеме — меняется и 3D; нажимаете на деталь в 3D — меняется опыт.

Образец стиля: уже готовые сцены электричества — `labs/phys-current/` и `labs/phys-circuits/`
(посмотрите `window.LUCH_REAL` в конце их скрипта и сцены `sceneWire/scenePower/sceneJoule` в `luch/real3d.js`).
Стиль: мультяшный (toon-свет в три тона), тёмный контур, тёплое дерево, яркие понятные цвета, подписи-«таблетки»
над главными деталями (название светлой таблеткой, значение — тёмной), ток — бегущие жёлтые огоньки по проводам.
Деталей много и они узнаваемы: винты, клеммы, подставки, шкалы. Всё, что показано, физически верно и совпадает
с числами опыта.

## Как подключить сцену

1. **В опыте** (`labs/<тема>/index.html`, внутри того же IIFE, рядом с `window.LUCH_CONTEXT`):
   ```js
   window.LUCH_REAL = () => {               // вызывается каждые 180 мс
     const m = model(), id = LID();           // как устроено состояние — смотрите сам опыт
     if (id === 'rub') return { scene: 'charge-rub', module: 'charge', help: 'Нажмите на палочку — потереть',
                                 rubbed: S.rubbed, q: Math.round(S.q * 10) / 10, ... };
     return null;                             // урок без сцены — переключатель скрыт
   };
   window.LUCH_REAL.click = key => { act(key); };   // что делать по нажатию на деталь в 3D
   ```
   - `scene` — имя сцены, `module` — имя файла сцен (`/luch/real3d-<module>.js`), `help` — подсказка внизу.
   - Остальные поля — данные для рисования. **Сцена перестраивается целиком, когда меняется JSON описания**,
     поэтому округляйте числа (до 0,1 или 0,5) и не кладите туда то, что меняется каждый кадр.
     Плавное движение (вращение мотора, качание стрелки, бег волны) делайте через `kit.onFrame`,
     вычисляя положение из времени и из (округлённых) параметров описания.
   - Если урок уже анимирован в опыте (например, ротор крутится с углом `S.ang`), передайте скорость/частоту,
     а угол считайте в `onFrame` сами.

2. **Файл сцен** `luch/real3d-<module>.js`:
   ```js
   (window.LUCH_REAL_SCENES = window.LUCH_REAL_SCENES || {})['charge-rub'] = (kit, d) => {
     const { T, at, box, cyl, mesh, v3, tag, clickable, C } = kit;
     const g = new T.Group(); at(g, 0, 0, 0);          // стол уже нарисован (верх стола y = 0)
     at(box(20, 2, 10, C.WOOD2), 0, 1, 0, g);          // подставка
     ...
     clickable(rod, 'rub');                            // по нажатию → window.LUCH_REAL.click('rub')
     tag(v3(0, 30, 0), 'Электроскоп', d.q + ' нКл');   // подпись над деталью
     kit.onFrame((dt, t) => { needle.rotation.z = ...; });  // анимация
   };
   ```
   Модуль `luch/real3d.js` сам загрузит файл, когда опыт впервые вернёт `module`.
   **`luch/real3d.js` не меняйте.** Если чего-то не хватает в наборе — сделайте у себя в файле сцен.

## Набор `kit` (всё уже есть)

- `T` — Three.js (r160). `kit.root` — текущая группа сцены (всё добавляйте через `at`, оно кладёт в `root`).
- `at(obj, x, y, z, parent?)` — поставить объект (в `parent` или в сцену), вернёт объект.
- `box(w, h, d, color, o?)`, `cyl(r, h, color, o?)` — деталь с мультяшным светом и контуром.
  `o`: `{ r2 }` верхний радиус (конус), `{ seg }` число граней (6 — гайка), `{ edges:false }`, `{ hull:false }`,
  `{ matOpt: { emissive, emissiveIntensity, transparent, opacity } }`, `{ mat }` — свой материал, `{ shadow:false }`.
  Цилиндр стоит по оси Y; лёжа — `obj.rotation.z = Math.PI/2` (вдоль X) или `rotation.x` (вдоль Z).
- `mesh(geometry, color, o?)` — любая геометрия (Sphere, Torus, Tube, Lathe…) в том же стиле. Для круглых
  тел передавайте `{ hull: true, edges: false }` — будет тёмный контур по силуэту.
- `toon(color, opts)` — материал в стиле сцены. `keep(x)` — зарегистрировать свою геометрию/текстуру
  для освобождения памяти (box/cyl/mesh делают это сами).
- `post(group, x, z, y0)` — клемма-стойка на высоте y0, вернёт точку верха (локально).
- `baseBlock(group, len, depth, h=2.4)` — деревянная подставка, вернёт её высоту.
- `cable(a, b, color, I, o?)` — провод-трубка из точки `a` в `b` (мировые `Vector3`), огоньки тока при `I>0`
  (скорость растёт с током). `o`: `{ lift }` подъём над клеммами, `{ arch:1 }` дугой, `{ via:[...] }` точки
  по пути, `{ r }` толщина. Цвета: `C.WIRE.plus/mid/minus/probeR/probeB`.
- `tag(point, name, value?, hot?)` — подпись над деталью (HTML, всегда читается). Не больше 5–6 на сцену.
- `clickable(group, key)` — деталь нажимается → `LUCH_REAL.click(key)`.
- `v3(x,y,z)` — `new T.Vector3`.
- Готовые приборы: `meter({kind:'A'|'V', val, max, value, label, click, small})`, `supply(U, unit?)`,
  `cells(n, U)`, `knife({closed, click})` (рубильник), `bulb({glow 0..1.6, value})`, `resistor({R, value, hot})`,
  `rheostat({f 0..1, value})`. Они возвращают `part {g, len, tin, tout, tag, top}`;
  поставить — `placeOn(part, v3(x,0,z), rotY, id)` → `{ g, tin, tout, tagAt }` (клеммы уже в мировых координатах).
- Текстуры: `textTex(txt, fg, bg, w, h)` (табло, текст сам вписывается), `dialTex(kind, val, max)` (шкала),
  `glowTex()` (свечение для `Sprite` с `AdditiveBlending`).
- `kit.onFrame((dt, t) => {...})` — анимация каждый кадр (секунды). Сбрасывается при перестройке сцены.
  `kit.reduce` — пользователь просит меньше движения: тогда ставьте статичную позу.
- Цвета `C`: `WOOD, WOOD2, BRASS, STEEL, DARK, INK`.
- Свет лампочки: `new T.PointLight(0xffc860, 60*g, 70, 1.2)` — освещает стол.

## Координаты и камера

- Y вверх, верх стола y = 0. Рабочее поле: **x от −62 до 62, z от −40 до 48** (z растёт к зрителю).
- Камера изометрическая, смотрит спереди-справа (с +x, +z) и сверху ~35°. Высокое ставьте назад (−z),
  приборы со шкалами — вперёд (+z), шкалы обращайте к зрителю (+z).
- Масштаб: лампочка на подставке ~17 в высоту, батарейка 15 в длину, рабочий объект урока — 30–60 в ширину.
- Сверху слева площадки лежит рамка задания, внизу — панель кнопок: самое важное держите в центре.

## Правила

- Меняйте только `labs/<ваша тема>/index.html` (добавить `LUCH_REAL` и `LUCH_REAL.click`) и свой
  `luch/real3d-<module>.js`. Другие файлы не трогайте. Не коммитьте и не пушьте.
- Bash-heredoc съедает обратные слэши — файлы пишите инструментом Write/Edit.
- Текст на русском. Подписи короткие.
- Каждый урок темы должен получить свою сцену. Если урок совсем не про предметы на столе
  (например, «Электромагнитные волны»), сделайте понятную настольную установку из учебного кабинета
  (передатчик-антенна и приёмник с лампочкой), а не абстрактную картинку.
- В конце — короткий отчёт: какие сцены, что в них нажимается, что анимировано, пути к PNG.
