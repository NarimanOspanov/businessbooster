# Телеграм-канал цен: запуск и проверка гипотезы

Дешёвая проверка тезиса «покупательский трафик можно набрать на ценах». Продукта нет, интерфейса нет — только канал. Если он не растёт органически, тезис о компараторе мёртв, и это выясняется за две недели, а не за два года.

## Что это

Два скрипта без единой зависимости:

| Скрипт | Что делает |
|---|---|
| `scripts/watchlist.js` | Собирает список популярных SKU с Kaspi (отбор по числу отзывов, не по скидке) → `data/watchlist.json` |
| `scripts/price-watch.js` | По каждому SKU спрашивает **всех продавцов**, запоминает минимальную цену и постит в канал, когда она падает |

Источник — `POST https://kaspi.kz/yml/offer-view/offers/{sku}`, тот самый эндпоинт из [карты доступа к данным](kz-retail-data-access-2026-08.md). Проверен вживую: 31 продавец по iPhone 16, минимум 477 272 ₸.

## Настройка

1. Создать канал в Telegram, добавить бота **администратором** с правом публикации.
2. Узнать chat_id канала: у публичного канала это `@username`, у приватного — числовой id вида `-100…`.
3. Добавить переменную окружения:

```
TELEGRAM_CHANNEL_ID=@your_channel
```

⚠️ Это **отдельная** переменная от `TELEGRAM_CHAT_ID` — та остаётся для личных операторских алертов о переходах. Токен бота (`TELEGRAM_BOT_TOKEN`) общий, уже настроен.

## Запуск

Собрать список отслеживаемых товаров (раз в неделю достаточно):

```bash
node scripts/watchlist.js 300
```

Прогнать проверку цен:

```bash
node scripts/price-watch.js
```

Посмотреть, что бы отправилось, ничего не публикуя:

```bash
node scripts/price-watch.js --dry
```

Пороги настраиваются: `--drop 3` (минимальное падение в процентах), `--min 2000` (минимальное падение в тенге), `--limit 8` (сколько постов за прогон максимум).

**Первый прогон ничего не публикует** — ему не с чем сравнивать, он только записывает базовые цены в `data/pricewatch.json`. Посты пойдут со второго.

Разумная частота — 2–3 раза в день. Прогон 300 SKU занимает ~7 минут при паузе 1,2 с между запросами.

## Формат поста

```
📉 Apple iPhone 16 128Gb NanoSIM+eSIM черный

477 272 ₸  ·  было 499 590 ₸  (−4,5%, −22 318 ₸)

Продавец: ITELL-KZ  ⭐ 4.8 (646)
Предложений на товар: 31

Открыть на Kaspi

Минимальная цена на Kaspi в Алматы на 11.08, 14:32
```

## Юридические ограничения, зашитые в код

Взяты из [due diligence по компаратору](price-comparison-research-2026-08.md), раздел «Юридический аспект»:

- **Никаких превосходных степеней.** Не «самая низкая цена в Казахстане», а «минимальная цена на Kaspi в Алматы на такое-то время». Любая превосходная степень требует документального подтверждения — ПК ст. 191, ЗРК «О рекламе» ст. 7, штраф до 1 500 МРП по КоАП ст. 163 ч. 2.
- **Каждая цена с таймстемпом и ссылкой на источник.** Достоверность рекламы — ЗРК «О рекламе» ст. 6 п. 1.
- **Никаких фотографий товаров.** Цена — факт и не охраняется (ЗРК № 6-I ст. 8), а фото и описания — самостоятельные произведения (ст. 7). В постах только название, цена и ссылка.
- **Только публичные эндпоинты, без обхода защиты.** Обход антибота или rate-limit подпадает под УК РК ст. 205. Пауза 1,2 с между запросами, никаких прокси и подмены челленджей.
- **Никаких персональных данных.** Имя продавца — это название торговой точки, телефоны и ФИО ИП не собираются (ЗРК № 94-V ст. 12 п. 2 требует хранения ПДн в РК).

## Критерий провала

Смотреть **только на органический рост подписчиков** — не на просмотры и не на количество постов.

Порог: **300+ подписчиков за 30 дней без платного продвижения**. Ниже — тезис «набрать покупательский трафик на ценах» не подтвердился, и дальше по этой ветке идти не нужно.

Причина, по которой порог именно такой: измеренная экономика ниши. e-katalog.kz — единственный выживший компаратор в стране — зарабатывает $769/мес. Аудитория, которая не растёт сама, до этой планки не доберётся тем более.
