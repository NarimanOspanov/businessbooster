# Листовка для агентов: что нести в типографию

Файлы собирает `scripts/leaflet-print.py`, тексты — в `scripts/leaflet_text.py`
(они общие с экранным одностраничником, чтобы цена и телефоны не разъезжались).

| Файл | Для чего |
|---|---|
| `reception365-listovka-a5.pdf` | в типографию: одна страница ровно 148×210 мм |
| `reception365-listovka-a4-2up.pdf` | на офисный принтер: A4 альбомный, две листовки, посередине линия реза |
| `reception365-listovka-a5.png` | посмотреть глазами, 600 dpi |
| `reception365-one-pager.png` / `.pdf` | экранная версия для WhatsApp, длинная, не для печати |

## Что говорить в типографии

- Формат A5 (148×210 мм), одна сторона — цветность **4+0**.
- Бумага **мелованная матовая 150 г/м²**. Тоньше 130 мнётся в сумке, толще — дороже без пользы.
- **Вылеты не нужны.** Фон белый, цветные блоки до края не доходят: даже если нож уйдёт на миллиметр, по краю всё равно белое поле.
- Разрешение 600 dpi, RGB. Для цифровой печати этого достаточно; если попросят CMYK — пусть конвертируют у себя, кроме бирюзового и тёмно-синего в макете цветов нет.
- Тираж: цифра выгодна до ~500 штук, дальше дешевле офсет. Цену уточняйте на месте — она сильно пляшет от города и бумаги.

## Про пустую строку внизу

«Промокод на скидку: ________» агент заполняет от руки своим кодом. Клиника
вводит его в форму на сайте, и заявка приходит с этим кодом — так видно, чья
она. Печатать код в тираже нельзя: он у каждого агента свой.

## Печать своими силами

Берите `-a4-2up.pdf`, в диалоге печати поставьте **масштаб 100 % / «Реальный
размер»** (не «вписать в страницу» — иначе поля уедут), лист A4 альбомный,
и разрежьте пополам по вертикали.
