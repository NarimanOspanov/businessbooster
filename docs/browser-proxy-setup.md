# Настройка браузера для сбора номеров с Крыши

Один экземпляр Chrome = один профиль Chrome + Tampermonkey со скриптом + FoxyProxy со своим
портом Asocks. На каждый следующий экземпляр всё повторяется с новым профилем и новым портом.

Понадобятся от руководителя:

- **ключ доступа** к серверу (длинная строка, вводится один раз в скрипт);
- **порт Asocks**: его id, адрес, порт, логин и пароль (с карточки порта в кабинете Asocks).

## 1. Профиль Chrome

Chrome → значок профиля справа вверху → «Добавить» → «Продолжить без аккаунта» → имя
профиля, например `krisha-1`. Откроется новое окно Chrome с чистым профилем. Всё дальше
делается в этом окне.

## 2. Tampermonkey и скрипт

1. Магазин Chrome → установить расширение **Tampermonkey**.
2. Открыть в этом окне адрес:

   ```
   https://saudager.ai/krisha-phone.user.js
   ```

   Tampermonkey покажет окно установки, нажать **Install**. Обновления скрипт потом получает сам.

3. Открыть любое объявление на krisha.kz, например `https://krisha.kz/a/show/1015901278`.
   Справа внизу появится тёмная панель скрипта. Она спросит ключ доступа: вставить его.
   Внизу панели видна версия, например **v3.6**.

## 3. FoxyProxy

1. Магазин Chrome → установить расширение **FoxyProxy**.
2. Значок FoxyProxy в панели браузера → кнопка **Options** внизу.
3. Слева **Proxies** → **Add**. Заполнить:

   | поле | что писать |
   |---|---|
   | Title | имя порта, например `kaz-1` |
   | Type | HTTP |
   | Hostname | адрес порта, например `109.236.84.23` |
   | Port | `9999` |
   | Username | логин порта, длинная строка вида `jxupugdoaz-…` целиком |
   | Password | пароль порта из кабинета Asocks |

4. **Save** внизу страницы.
5. Снова значок FoxyProxy → в выпадающем списке вместо «Disable» выбрать свой прокси.
   Значок станет цветным.
6. Проверка: в том же меню кнопка **IP** должна показать казахстанский адрес, а не свой.

## 4. Порт в скрипте

На странице объявления в панели скрипта внизу есть ссылка **«порт общий»**. Нажать, ввести
**id порта** (число, например `238006260`) → OK. В панели станет «порт 238006260».

Это важно: скрипт перед каждым следующим объявлением меняет IP именно у этого порта.
Если оставить «общий», смена IP одним браузером сломает страницы всем остальным.

## 5. Работа

- Открыть любое объявление на krisha.kz и оставить вкладку **на экране**. Дальше скрипт
  всё делает сам: нажимает «Показать телефон», сохраняет номер, меняет IP, открывает
  следующее объявление.
- **Капча решается вручную.** Когда она появилась, панель пишет «Капча — решите её». На это
  минута; если не успели, страница перезагрузится сама, всего до двух перезагрузок, потом
  скрипт перейдёт к следующему объявлению.
- В **фоновой вкладке** скрипт ничего не делает и пишет «Вкладка в фоне — жду, пока её
  откроют». Работает только вкладка, которая на экране, поэтому держать много вкладок
  смысла нет: одна вкладка на окно.
- Окно согласия на cookies, которое Крыша показывает после смены IP, скрипт закрывает сам.

## 6. Если что-то не так

| в панели | что значит | что делать |
|---|---|---|
| нет панели вообще | скрипт не установлен или выключен | Tampermonkey → проверить, что скрипт включён |
| «Без ключа сохранять некуда» | ключ не введён | обновить страницу, ввести ключ |
| «Не сохранилось: bad_key» | ключ неверный | ввести ключ заново |
| «Порта … нет в Asocks» | id порта введён с ошибкой | нажать «порт», исправить |
| «Прокси на сервере не настроен» | сервер не видит Asocks | сообщить руководителю |
| «Очередь пуста» | объявлений по фильтру нет | подождать, очередь пополняется каждую минуту |
| IP в FoxyProxy не казахстанский | прокси не включён или неверный пароль | проверить Options и выбрать прокси в меню |
