# Телефон для снятия номеров с Крыши: установка и настройка

Телефон на Android берёт из очереди saudager.ai объявление хозяина без номера,
открывает его в приложении Крыши, нажимает «Позвонить», читает номер из шторки
и отправляет на сервер. Работает через Tasker + AutoInput, рут не нужен.

Проверено на двух телефонах: Samsung и Redmi (Xiaomi, HyperOS), октябрь 2026.

## 1. Что установить

1. **Tasker** из Google Play, разовая покупка (~1 500 ₸).
2. **AutoInput** (плагин к Tasker, разработчик joaomgcd). Лицензия покупается
   через приложение **AutoApps** того же разработчика: AutoApps → AutoInput →
   Unlock, ~2 000 ₸ разово. Без лицензии AutoInput не работает.
3. **Крыша** (krisha.kz).

Лицензии привязаны к Google-аккаунту: на втором телефоне войти в тот же
аккаунт, и покупки подтянутся.

## 2. Системные настройки

Делать для **Tasker**, **AutoInput** и **AutoApps**. На Xiaomi эти ограничения —
главная причина сбоев.

**Специальные возможности.** Настройки → Расширенные настройки → Специальные
возможности → Скачанные приложения → **AutoInput → Вкл**.
- Если переключатель серый («Ограниченная настройка», Android 13+): Настройки →
  Приложения → AutoInput → ⋮ → «Разрешить ограниченные настройки», потом включить.
- После перезагрузки проверять, что служба осталась включённой.

**Батарея.** Настройки → Приложения → Все приложения → (приложение) → Батарея →
**«Нет ограничений»**.

**Другие разрешения** (на той же странице «О приложении», ниже). Разрешить всё:
- «Запуск в фоне»;
- «Отображать всплывающие окна, когда запущено в фоновом режиме»;
- «Всплывающие окна» / «Поверх других приложений»;
- «Постоянные уведомления».

**Автозапуск.** Настройки → Приложения → Разрешения → **Автозапуск** → включить
Tasker, AutoInput, AutoApps.

**«Приостановить работу приложения, если оно не используется»** — выключено.

**Ссылки Крыши.** Настройки → Приложения → Крыша → Открывать по умолчанию →
поддерживаемые ссылки → Вкл, чтобы объявления открывались в приложении,
а не в браузере.

**Недавние приложения.** Закрепить карточки Tasker и AutoInput замком, чтобы
система их не выгружала.

## 3. Настройки AutoInput

В самом приложении AutoInput:
- **Accessibility In Foreground — Вкл** (постоянное уведомление, защищает службу
  от выгрузки; по описанию обязательно на Android 8+);
- **Enable Just When Needed — Выкл**.

## 4. Задача в Tasker

Импортировать XML задачи `Krisha` (файл передаётся отдельно, в нём ключ
очереди открытым текстом — не публиковать). После импорта поправить:

- **Шаг с отправкой номера** (HTTP POST с `"phones"`): `"src":"phone…"` —
  своё имя телефона, например `phoneRedmi`. По нему телефоны различаются в
  «Консоли номеров».
- **Шаг с промахом** (HTTP POST на `/objphone/miss`): `"reason":"no_phone"`
  вместо `archived`. `archived` навсегда убирает объявление из очереди,
  `no_phone` ставит на паузу, и объявление вернётся позже.
- **Шаг AutoInput UI Query**: отметить «Продолжить задачу после ошибки», чтобы
  при сбое задача сообщила промах и перешла к следующему объявлению, а не
  крутила одно и то же.

Шаблон номера в UI Query и в «Поиск и замена»: `\+7 \d{3} \d{3} \d{4}`, галочка
Regex. Крыша отдаёт номер как `+7 747 291 4002`, на Samsung и Redmi одинаково.

## 5. Проверка

Открыть «Консоль номеров» (saudager.ai → Консоль номеров). У каждого телефона
своя метка `src` и счётчик за 10 минут. Норма — номер с телефона каждые 5–7 секунд,
промахов почти нет. Зачёркнутые номера в строках — «прилипшие» с прошлого
объявления, сервер их отбрасывает сам.

## 6. Если не работает

**Крутит одно объявление по кругу.** Шаг UI Query не дождался номера
(«Action timed out» в журнале задачи) и задача оборвалась до отправки. На
Xiaomi в октябре 2026 это лечилось разделами 2–3: после того как AutoInput и
Tasker получили автозапуск, «Нет ограничений» по батарее и все «Другие
разрешения», задача заработала. Какой именно пункт решил дело, не выясняли —
делать все.

**Задача не запускается по ▶.** В фоне висит предыдущий запуск. Настройки →
Приложения → Tasker → Остановить, открыть Tasker заново.

**Посмотреть, что видит AutoInput.** Отдельная задача из трёх шагов:
1. Ждать 12 с;
2. AutoInput UI Query с пустым фильтром Text;
3. HTTP-запрос POST на
   `https://saudager.ai/api/krisha/objphone/debug?key=КЛЮЧ&src=имя` с телом
   `%aitext()` — **со знаком %**, без него Tasker отправит слово `aitext()`
   вместо текста.

Нажать ▶, переключиться в Крышу на открытую шторку с номером. Текст экрана
сохраняется в таблицу `dbo.objphone_debug`.

Всплывающие окна Tasker («Сигнал → Всплывающее окно») на Xiaomi из фона не
показываются, поэтому для отладки отправляем текст на сервер.
