# Подключение клиники: от купленного номера до первого звонка

Порядок один и тот же для каждого клиента. Ключи нигде не пишем в переписке:
скрипты берут их из файлов в домашней папке.

| Что нужно | Где лежит |
|---|---|
| Ключ и секрет API Zadarma | `~/.zadarma-keys`, две строки: ключ, потом секрет |
| Ключ ElevenLabs | `~/.elevenlabs-key` |
| Строка подключения к базе | `~/.azure-sql-connection` |

Посмотреть, что вообще есть сейчас:

```bash
node scripts/assign-number.js --list
```

## 1. Номер в Zadarma

Купили виртуальный номер — на странице заказа оставьте **«Через виртуальную
АТС»** и сохраните. Два других варианта (SIP-программа, переадресация на
телефон) ведут мимо нашей схемы.

## 2. Провести номер в работу

```bash
node scripts/provision-number.js --number=+7727XXXXXXX --free
```

Скрипт заводит **отдельный** внутренний номер АТС (занятые другими номерами он
обходит — на одном внутреннем два номера жить не могут, иначе звонки уедут
чужой клинике), ставит на него переадресацию на SIP ElevenLabs, импортирует
номер в ElevenLabs и кладёт в пул. Падение на середине не страшно: запускается
повторно.

`--free` значит «номер активирован у оператора и готов к выдаче». Если ещё нет
— запускайте без флага, номер ляжет как `preparing`.

Дальше **в панели Zadarma**: «Моя АТС» → входящие звонки этого номера
направить на тот внутренний, который назвал скрипт. Это единственный шаг,
который API не делает.

## 3. Анкета клиники

Клиника заводится на организацию Clerk, **одна клиника на организацию**.
Поэтому анкету заполняем из аккаунта клиента, а не из своего: под своим
аккаунтом мастер обновит демо-клинику «Нариман Дент», а не создаст новую.

Заходим на `/start/` (страница скрыта в меню, работает по прямому адресу),
входим под почтой клиники и проходим четыре шага. На первом достаточно ссылки
на 2GIS — оттуда подтягиваются адрес, часы и телефон; сайт и Instagram
добавляют услуги.

Что обязательно проверить руками перед «Включить»:

- **Услуги и цены.** Чего нет в этом поле — ассистент не назовёт. Это главное
  поле, остальное второстепенно.
- **Часы работы** — по ним он говорит, когда клиника открыта.
- **Как записывать** — подтверждать время сразу или обещать звонок
  администратора.
- **Острая боль** — куда направлять ночью.

Кнопка «Включить» создаёт агента клиники и сохраняет анкету.

## 4. Привязать номер к клинике

```bash
node scripts/assign-number.js --number=+7727XXXXXXX --clinic=<id>
```

Скрипт закрепляет номер за клиникой и переставляет его в ElevenLabs с базового
агента на агента клиники — без этого пациент услышит демо-ассистента. Id
клиники смотрите в `--list`. Если номер лежит как `preparing`, добавьте
`--ready`.

## 5. Переадресация со своего номера клиники

Клиника набирает на телефоне, куда сейчас звонят пациенты:

- `**61*+7727XXXXXXX**25#` — если не ответили за 25 секунд (шесть гудков);
- `**62*+7727XXXXXXX#` — если телефон вне зоны;
- `**67*+7727XXXXXXX#` — если занято.

Проверить: `*#61#`. Снять всё: `#002#`. На iPhone коды не проходят при
включённом Wi-Fi Calling — сначала выключить.

Подробности и подводные камни — в [call-list-instructions.md](call-list-instructions.md).

## 6. Проверка

1. Позвонить на новый номер, поговорить с ассистентом.
2. Открыть кабинет: запись, расшифровка и карточка звонка должны появиться.
3. Убедиться, что уведомление пришло в Telegram.
4. Позвонить на номер клиники и не брать трубку — звонок должен уйти
   ассистенту через переадресацию.

Если в кабинете пусто, а звонок был: почти всегда номер в ElevenLabs остался
на старом агенте. Проверяется тем же `assign-number.js --list`.
