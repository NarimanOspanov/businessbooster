# API: телефоны хозяев квартир

Один эндпоинт, домен `https://saudager.ai`, поведение зависит от HTTP-метода.
Ключ доступа — один и тот же во всех запросах, передаётся в query-строке.

```
KRISHA_PHONE_KEY = <значение из ~/.krisha-creds на сервере>
```

Без верного `key` любой запрос отвечает `403 {"ok":false,"error":"bad_key"}`.

Старый адрес `https://saudager.ai/api/krisha/queue` — алиас на `GET` без `id`
(тот же режим «список без номера»), оставлен для обратной совместимости.

---

## GET — список квартир без сохранённого номера

```
GET https://saudager.ai/api/krisha/phone?key=<KEY>&limit=30
```

| Параметр | Обязателен | Описание |
|---|---|---|
| `key` | да | ключ доступа |
| `limit` | нет | размер пачки, по умолчанию 30 |

**Ответ 200:**
```json
{
  "ok": true,
  "count": 30,
  "total": 29337,
  "items": [
    { "id": "1015679231", "title": "1-комнатная квартира · 34 м² · 4/7 этаж",
      "url": "https://krisha.kz/a/show/1015679231" }
  ]
}
```

- `count` — сколько объявлений в этой пачке (≤ `limit`).
- `total` — сколько всего в очереди без номера, по всей базе.
- `items` — свежие объявления идут первыми.

---

## GET — что уже сохранено по одной квартире

```
GET https://saudager.ai/api/krisha/phone?key=<KEY>&id=1015679231
```

| Параметр | Обязателен | Описание |
|---|---|---|
| `key` | да | ключ доступа |
| `id` | да | номер объявления на Крыше |

**Ответ 200:**
```json
{
  "ok": true,
  "id": "1015679231",
  "phones": ["+7 705 111 22 33"],
  "raw": ["77051112233"]
}
```

- `phones` — номера в читаемом виде.
- `raw` — те же номера цифрами, `7XXXXXXXXXX` (11 цифр, без `+`).
- Если номеров нет — `phones` и `raw` пустые массивы, `ok` всё равно `true`.

Смотреть это перед правкой — чтобы не перезаписать номер вслепую, не видя,
что там сейчас.

---

## POST — сохранить номер (добавить к тому, что уже есть)

```
POST https://saudager.ai/api/krisha/phone?key=<KEY>
Content-Type: application/json

{ "id": "1015679231", "phones": ["+7 705 111 22 33"] }
```

| Поле тела | Обязателен | Описание |
|---|---|---|
| `id` | да | номер объявления |
| `phones` | да | массив номеров (можно и одно строкой в `phone`) |

Номер разбирается из любого написания: `+7 705 111 22 33`, `87051112233`,
`7051112233` — итог всегда `7XXXXXXXXXX`.

**Ведёт себя как «добавить», не «заменить»**: старые номера этой квартиры не
трогает, только дописывает новые. Нужно для скрипта, который снимает номер со
страницы и может перезапуститься на той же квартире — старый номер не должен
потеряться.

**Ответ 200:**
```json
{ "ok": true, "id": "1015679231", "phones": ["+7 705 111 22 33"] }
```

**Ошибки:**
- `400 {"ok":false,"error":"нет номера объявления"}` — не передан `id`.
- `400 {"ok":false,"error":"номер не разобрал"}` — в `phones` не нашлось ни
  одного валидного номера.

## PUT / PATCH — заменить номера целиком

```
PUT https://saudager.ai/api/krisha/phone?key=<KEY>
Content-Type: application/json

{ "id": "1015679231", "phones": ["+7 701 000 00 00"] }
```

То же тело, что у `POST`, но **стирает все прежние номера этой квартиры и
записывает только те, что переданы**. Это единственный способ поправить
ошибочно сохранённый номер — `POST` только добавляет, никогда не удаляет.

**Пустой список — осознанная очистка:**
```json
{ "id": "1015679231", "phones": [] }
```
удаляет все номера квартиры. Если поле `phones`/`phone` в теле вообще
отсутствует — это трактуется как ошибка запроса, а не как очистка:

```
400 {"ok":false,"error":"нужен список phones (может быть пустым)"}
```

`PATCH` работает идентично `PUT`.

**Ответ 200:**
```json
{ "ok": true, "id": "1015679231", "phones": ["+7 701 000 00 00"] }
```

## CORS

Эндпоинт вызывается напрямую со страницы `krisha.kz` (браузерным скриптом),
поэтому отдаёт:

```
Access-Control-Allow-Origin: https://krisha.kz
Access-Control-Allow-Methods: GET, POST, PUT, PATCH, OPTIONS
Access-Control-Allow-Headers: Content-Type
```

`OPTIONS`-запрос (preflight) отвечает `204` без тела.

---

## Сводка

| Метод | URL | Что делает |
|---|---|---|
| `GET` | `/api/krisha/phone?key=&limit=` | список квартир без номера |
| `GET` | `/api/krisha/phone?key=&id=` | номера одной квартиры |
| `POST` | `/api/krisha/phone?key=` + body | добавить номер |
| `PUT` / `PATCH` | `/api/krisha/phone?key=` + body | заменить номера целиком |
