# Мульти-маркетплейс селлеры KZ: боли, «единые кабинеты», фулфилмент (август 2026)

Ресёрч по ~20 источникам (Habr, форумы селлеров, документация Kaspi, сайты вендоров). Полные ссылки — в истории ресёрча.

## 1. Боли селлеров на 2–3 маркетплейсах (по убыванию остроты)

1. **Рассинхрон остатков → отмены → бан.** У Kaspi отмены >5% заказов = приостановка магазина на 7 дней (или расторжение). Товар продался на WB, остаток на Kaspi не обновился — и селлер под баном. Это боль №1, экзистенциальная.
2. **Критическая особенность Kaspi API: метода обновления остатков НЕТ.** Остатки/цены — только через XML-прайслист, который Kaspi опрашивает раз в ~30 минут (habr.com/ru/articles/806447). Нет песочницы, тестят на живых заказах. Интеграция с Kaspi «feasible but fiddly» — реальный ров для того, кто сделает её хорошо.
3. **Демпинг.** Kaspi: одна карточка — много продавцов, ранжирует цена → целая индустрия демпер-ботов (SaleScout 35–100k ₸/мес, ibot.kz, AlgaTop, Cube Demper...), перепроверка цены каждые ~3 минуты.
4. **Ценовой паритет Kaspi**: требует одинаковых цен во всех каналах селлера → любой репрайс каскадится на WB/Ozon.
5. **Разные модели логистики**: Kaspi — только FBS (своего склада-FBO у Kaspi НЕТ), возвраты физически едут селлеру; WB/Ozon — FBO со складами. Три ментальные модели одновременно.
6. **Дублирование карточек**: у каждого маркетплейса своя схема; карточки Kaspi создают руками/XML, нанимают фрилансеров.
7. **Раздробленная аналитика**, особенно слабая по Kaspi/Halyk/Forte.

**Масштаб**: Kaspi ~721k активных селлеров (H1 2024); WB KZ ~16k реально торгующих; Ozon ~45k регистраций. Настоящих мульти-хомеров — десятки тысяч (не сотни).

## 2. «Единый кабинет» — кто уже есть

| Инструмент | Kaspi? | Цена | Вердикт |
|---|---|---|---|
| **МойСклад** | Да, но через сторонний коннектор | free tier + платно | Инкумбент, но это тяжёлый ERP, не «кокпит селлера» |
| **Market Radar** (KZ) | Да (ядро), офиц. техпартнёр Kaspi и Forte, 12 платформ | **65–95k ₸/мес** | Прямой конкурент, но ценой отсекает малых |
| SelSup / Topseller / Sellego / SellerDen (RU) | **НЕТ** | от 1 800 ₽ | Российские мульти-тулзы Kaspi игнорируют |
| Kaspi-демперы/аналитика (SaleScout, ibot, AlgaTop, SellStat...) | только Kaspi | 5–100k ₸/мес | Многолюдно, но одноканально |
| Кастомные 1С-интеграции (OptimalSoft, FAVOR-IT, OSN) | да, проектно | **300k–2.5M ₸ разово** | Цена кастома = доказательство неудовлетворённого спроса |

**Вывод**: настоящих «единых кабинетов» для KZ — полтора (МойСклад тяжёлый, Market Radar дорогой). **Открыта ниша дешёвого (~15–30k ₸/мес) Kaspi-first кабинета для малых и средних.**

## 3. Фулфилмент (присланные сервисы + ландшафт)

- **CDEK Fulfillment** (ffcdek.kz) — сильнейший: склады Алматы/Астана, FBO/FBS/DBS, прямая API-интеграция с Kaspi и Flip, без абонплаты (оплата за операции), до −40% на доставку.
- **NeSklad.kz** — для новичков и российских селлеров без юрлица в KZ: приём/хранение/упаковка/отправка «от единичных штук», обработка в день заказа.
- **Rapido Fulfillment** (Алматы) — 3PL: приёмка, ОТК, сборка, кросс-докинг, **маркировка (аналог «Честного знака» — ИС МПТ)**, подготовка FBO для WB/Ozon; хранение 250 ₸/паллет-день.
- Контекст: **у Kaspi нет собственного FBO** — потому ниша 3PL структурно устойчива. WB/Ozon в 2026 расширяют склады в KZ (проблемы российской логистики) — попутный ветер для местных 3PL. Маркировка ИС МПТ (обувь с 2021, одежда до 2027, штрафы с 2025) — растущая compliance-боль.

## 4. Выводы для Saudaget

1. **«Единый кабинет» — да, это наша фича**, и связка уникальна: никто из ops-инструментов не даёт селлеру «внешний» актив (витрина + фиды + AI-видимость), никто из visibility-инструментов не делает ops. Ежедневный кабинет решает проблему retention, которой болеют чистые AI-visibility продукты.
2. **Порядок наращивания (по риску)**: каталог Kaspi → AI-витрина/фиды (есть) → публикация карточек на WB/Ozon (дёшево, безопасно) → синк остатков/цен (высочайшая ценность, но и риск: баг = бан клиента по правилу 5% — делать в последнюю очередь и осторожно) → агрегация заказов → репрайсер.
3. **Приоритет интеграций**: Kaspi merchant API + XML-прайс (ров) → Ozon Seller API → WB API → Halyk → Forte/Uzum. Плюс экспорт в 1С (потребуют бухгалтеры).
4. **Фулфилмент — партнёрство, не стройка**: кнопка «отгружать через CDEK/Rapido» в кабинете (роутинг заказов + видимость остатков через их API). Цифровую часть маркировки ИС МПТ можем взять на себя.
5. **Риски**: у Market Radar фора и статус партнёра Kaspi (дифференцируемся ценой + витриной/фидами, не паритетом синка); Kaspi может выпустить свой FBO/богатый API; мульти-хомеров десятки тысяч → монетизировать и Kaspi-only большинство (это делает как раз AI-витрина).
