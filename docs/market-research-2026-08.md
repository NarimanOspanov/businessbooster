### Боли и критика (из отзывов G2/Reddit/HN)

1. **«Мониторинг без исправления»** — критика №1. «$300–3000/мес за софт + 20–40 часов труда — дашборд становится дорогим отчётом, по которому никто не действует».
2. **Валидность измерений шаткая**: LLM недетерминированы — «меньше 1 из 100 прогонов промпта возвращает тот же список брендов»; инструменты показывают ложную точность.
3. **Google (05.2026) официально**: «оптимизация под генеративный ИИ — это всё ещё SEO», llms.txt / чанкинг / AI-разметка названы неэффективными «GEO-хаками».
4. Скрытые доплаты за движки; кредитные модели; категория пишет отзывы сама о себе (вендоры «ревьюят» конкурентов).

### Пробелы рынка (наши возможности)

- **Дёшево + «сделаем за вас» для локального SMB — пусто.** Никто не даёт «аудит → автоисправление → готово» для парикмахерской по цене consumer-SaaS.
- **Транзакционный/агентный слой строят платформы, не GEO-вендоры**: Shopify раздал мерчантам MCP по умолчанию (06.2026), но **сервисные SMB (записи, брони, меню — не товарные каталоги) и мерчанты вне больших платформ не обслужены никем**.
- **Честные измерения** (доверительные интервалы вместо ложной точности) — никто не делает.

## 2. Как реально работает AI-поиск (инженерные факты)

### Архитектура по провайдерам

- **ChatGPT**: ретривал через **индекс Bing** + собственный индекс (OAI-SearchBot). 87% цитат SearchGPT совпадают с топ-10 Bing (Seer Interactive). **Ранжирование в Bing — главный предиктор цитирования в ChatGPT.** Боты: GPTBot (обучение), OAI-SearchBot (поиск), ChatGPT-User (живая загрузка). Блокировать GPTBot можно, OAI-SearchBot — нельзя.
- **Perplexity**: свой индекс (PerplexityBot) + гибрид. Recency — самый сильный сигнал; Reddit — 46.7% цитат. Скандал: Cloudflare поймала Perplexity на скрытом краулинге (08.2025).
- **Claude**: поиск через **Brave Search** (40B+ страниц) + живая загрузка страниц (Claude-User).
- **Google AI Overviews / Gemini**: классический индекс Google + **query fan-out**. Официально: «не нужны никакие AI-файлы и спец-разметка». Локально — всё из **Google Business Profile**.
- **Copilot**: индекс Bing. **IndexNow** даёт индексацию за часы. Bing Webmaster Tools теперь показывает отчёт «AI Performance» (цитаты!).

### Критические факты

1. **Ни один AI-краулер, кроме Google и Apple, НЕ исполняет JavaScript** (Vercel/MERJ: ноль случаев на сотнях миллионов запросов). SSR — жёсткое требование. ✅ Наш тезис «сайт-мост должен рендериться сервером» подтверждён.
2. **llms.txt не читает никто.** 97% файлов llms.txt получают ноль запросов (Ahrefs, 137K сайтов). Джон Мюллер: «ни одна AI-система его не использует». ❌ Убрать из оффера как «фичу», оставить как копеечную страховку.
3. **Schema.org**: прямого эффекта на цитирование не доказано, но косвенный есть (Bing/Copilot подтвердили использование; продуктовые фиды с GTIN — прямой канал).
4. **68% всех цитат** — Reddit, Wikipedia, YouTube, LinkedIn, Forbes. Форматы-чемпионы: списки-сравнения, how-to, FAQ.
5. **Локальные рекомендации = переранжирование агрегаторов**: Yelp (теперь официальный партнёр OpenAI, 07.2026), Google Business Profile, Bing Places, отзывы. Почти половина локальных цитат ChatGPT — сторонние сайты, не сайты бизнесов.
6. **Instant Checkout закрыт OpenAI в марте 2026** (конверсия в чате хуже, чем на сайте мерчанта) → выжил канал **продуктовых фидов** (chatgpt.com/merchants, органическое ранжирование). У Perplexity — бесплатный Merchant Program (каталог → их индекс).

## 3. Вердикт по реализуемости

### Что подтвердилось

- Тайминг реален: AI-рефералы выросли ~16x за 2024–2026; конверсия AI-трафика в ~23 раза выше органики (Ahrefs: 0.5% трафика → 12.1% регистраций).
- Инвесторы верят: $300M+ в категорию за год, Profound — юникорн.
- Пробел «сделать за SMB, а не мониторить» — реален и пуст.

### Что опроверглось (важно!)

1. **Поддомены-мосты = «doorway pages».** Дубликат сайта бизнеса на нашем поддомене: (а) проиграет каноникализацию оригиналу, (б) подпадает под политики Google/Bing о doorway/scaled content/site reputation abuse, (в) один спамный тенант на `*.platform.com` топит всех. Ни одного позитивного прецедента сети поддоменов, зарабатывающей AI-цитаты, не найдено.
2. **AI почти не рекомендует малый бизнес напрямую**: SOCi (350K локаций): ChatGPT рекомендует 1.2% локаций против 35.9% попадания в Google 3-pack. Рекомендации идут через агрегаторы.
3. **Абсолютные цифры пока малы**: AI-платформы = ~0.32% всего веб-трафика (2026). SMB уйдёт, если платить $199/мес за два визита.
4. **llms.txt — плацебо** (см. выше).
5. **Платформенный риск**: OpenAI+Yelp, OpenAI+Shopify/Walmart/Etsy — гиганты строят прямые трубы к бизнесам.

### Жизнеспособная версия продукта (по данным)

1. **Целиться в бизнесы БЕЗ сайта** (Instagram-first) — для них «мост» не дубликат, а единственное краулируемое представительство. И на **их собственном домене** (или купленном для них), не на нашем поддомене.
2. **Продавать работу с агрегаторами**: Google Business Profile + Bing Places + Yelp/2GIS + скорость отзывов — то, что ИИ реально цитирует. Автоматизировать это = наш «агент делает за вас».
3. **SSR-витрина** обязательна (наш план и так такой). Schema.org — да; llms.txt — не обещать.
4. **Фиды**: продуктовый фид в chatgpt.com/merchants и Perplexity Merchant Program — прямой, бесплатный, органический канал в AI-шопинг. Быть слоем онбординга в эти фиды для длинного хвоста — сильная идея.
5. **MCP для сервисных SMB** (брони/записи/квоты) — белое пятно: Shopify закрыл товары, сервисы не закрыл никто. Наш «Этап 1.5» бьёт точно туда.
6. **Честная аналитика**: показывать AI-трафик мерчанту (рефералы chatgpt.com/perplexity.ai + визиты ботов) с честными интервалами — дифференциатор.
7. **Рынки со слабыми агрегаторами** (Центральная Азия/СНГ, где нет Yelp) — единственный контекст, где «мост» имеет прямой причинный путь к цитированию. Ирония: для US-рынка нужны агрегаторы и фиды, для домашнего — мосты работают лучше.
